# INF04_01-2025_ReactApp

## Description
A React.js web app from the INF.04 January 2025 exam. The app implements core requirements from the official exam task.

## Features
- Dynamically displaying images based on filters
- Increasing download counter for each image after pressing the download button

<p align="center"><img src="https://i.imgur.com/uCi6OCX.png" alt="App Screenshot"></p>

## Technologies
- Node.js
- React.js
- Bootstrap

## Installing
1. Make sure that you have node and npm installed
2. Clone the project in bash

    ```bash
   git clone https://github.com/KeneKbee/INF04_01-2025_ReactApp.git
    ```
2. Change directory to project
    ```bash
   cd INF04_01-2025_ReactApp
    ```
2. Install node modules and libraries
    ```bash
   npm install
    ```
<br>
<p align="center"><img src="https://i.imgur.com/xb5fsmG.png" alt="App Screenshot"></p>

## Running the app
Open the project path in cmd and type `npm start`
